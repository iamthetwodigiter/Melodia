# Melodia

Minimal Music Streaming/ Downloader/ Player App created with Flutter 💙

![GitHub All Releases](https://img.shields.io/github/downloads/iamthetwodigiter/melodia/total?label=Downloads&logo=GitHub)

## Features

- Stream Music in [48, 96, 160, 320] kbps qualities
- Download Music in [48, 96, 160, 320] kbps qualities
- Add songs to user playlist
- Add complete playlist/album to library
- Favorite songs
- Separate sections for online and offline user playlists, albums and favorites
- Music slab for quick controls
- Lyrics support
- View next playing songs queue
- Shuffle Mode
- Repeat Mode
- Appwide accent color
- Search songs
- Clear watch history
- Suggested songs at the end of searched songs
- And many more, find yourself....
